Instagram paylaşım planlayıcısı (Android) ve içerik deposu.

- **Uygulama:** [EvrimArsivi.apk](https://github.com/olcaydunder/evrim-arsivi/releases/download/app/EvrimArsivi.apk) — telefona indirip kurun.
